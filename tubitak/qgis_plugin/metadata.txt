qgisMinimumVersion=3.28

description=Generate a georeferenced synthetic 10 m reference raster from OSM and CLC+ over a chosen extent.
about=Renders OpenStreetMap vectors over a CLC+ Backbone land-cover base in the GenCP visual convention, runs a pix2pix generator via onnxruntime, and mosaics the result into a single georeferenced GeoTIFF on a 10 m grid. Adds the result as a QGIS layer and/or writes it to disk. Matching and GCP extraction are out of scope - a separate application consumes this output. All generation logic lives in gencp_core, which imports neither Qt nor QGIS. VERIFIED ON: QGIS 4.2.1 (Qt 6.11.1 / PyQt 6.11.0) on macOS, executed end to end. NOT YET VERIFIED: any QGIS 3.x load, and any Windows load. All Qt access goes through the qgis.PyQt shim and no Qt5-only or Qt6-only API is used, so 3.28 LTR is reasoned about rather than tested. Requires onnxruntime in the QGIS Python; osmium additionally for the local .osm.pbf source.
