# GenCP VHR Deblurring Demo

This repository provides a demonstration of the LaKDNet model for image deblurring on high-resolution synthetic blurry images. The notebook included showcases the deblurring performance along with the resulting outputs.

## Dataset

The `gencp_VHR_deblurring_data_test` directory contains the following:

- **input**: Synthetic images generated by running **GenCP_demo_VHR.ipynb**  
- **masks**: The corresponding masks of the images  
- **target**: The original (ground-truth) images

**Note:** To generate the synthetic images, first run the notebook `GenCP_demo_VHR.ipynb` to produce the required **output** directory and corresponding **.tif** files. These outputs, along with the dataset, are used as input for the deblurring stage.

## Model

The LaKDNet model can be accessed at the following link:  
[LaKDNet GitHub Repository](https://github.com/lingyanruan/LaKDNet)  

**Note:** The repository indicates that the implementation uses **PyTorch**.

The model weights were produced by fine-tuning on the VHR dataset for 20 epochs.  
Download the weights here:  
[Model Weights Link for deblurring](https://mega.nz/file/XLBnAbwK#oB6VTNxJa506adn9GK8NQg3sfWvG7lIjqXt8PW-MuNk)

## Output

The deblurred images produced by the model are saved in the directory:  
**`./output_lakdnet/`**

## Usage

1. Prepare the synthetic images by running `GenCP_demo_VHR.ipynb`.
2. Place the dataset and generated synthetic images in `gencp_VHR_deblurring_data_test`.
3. Run the deblurring notebook to obtain the outputs in `./output_lakdnet/`.

## Compatibility

This notebook and code have been tested and are compatible with the **latest version of Google Colab** and **Python 3.12**.
